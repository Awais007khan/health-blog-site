# Health Blog Website – Next.js

A modern and responsive Health Blog Website built using **Next.js** and **Tailwind CSS**.

## Features

- Responsive UI (Mobile + Desktop)
- SEO-friendly structure
- Dynamic blog pages
- Categories section
- Contact & Write For Us forms
- EmailJS integration
- Reusable components
- Mobile responsive navbar

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- EmailJS

## Pages

- Home
- Blogs
- Categories
- Contact
- Write For Us
- Dynamic Blog Page

## Run Project

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Learning Outcomes

- Next.js App Router
- Dynamic Routing
- SEO in Next.js
- React to Next.js migration
- Responsive UI development
